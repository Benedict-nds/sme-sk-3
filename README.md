# SME skills

Seven skills for the SME digitization project. Each folder holds one SKILL.md.

- house-rules: shared rules for every agent
- source-comparison: intake form (PDF or CSV) vs transcript and summary
- client-needs-brief: one-page brief per client
- need-triage: digital now / later / non-digital / not realistic
- check-against-client-notes: reviewer's checks
- cross-client-patterns: problems that repeat across clients, from the portfolio folder only
- roadmap-builder: phased roadmap and timeline for one client

Import each folder into Paperclip (Skills, then My Skills), then enable the right skills on each agent.
